# **Data Structures and Algorithms (DSA) Overview**


## **1. Introduction**

Data Structures and Algorithms (DSA) are the foundation of programming and software development. They help solve problems efficiently and optimize the performance of programs.

Data Structure: A way to organize and store data for efficient access and modification.

Algorithm: A step by step procedure to solve a specific problem.

Why DSA is important:

Makes code efficient and optimized.

Helps solve complex problems.

Essential for technical interviews.

Handles large datasets effectively.


## **2. Data Structures**

2.1 Linear Data Structures

Array – Fixed size, contiguous memory. Access by index (O(1)), insertion/deletion (O(n)).

Linked List – Nodes connected via pointers. Types: Singly, Doubly, Circular. Insert/Delete O(1) if position known.

Stack (LIFO) – Push, Pop, Peek. Used in recursion, undo operations, expression evaluation.

Queue (FIFO) – Enqueue, Dequeue. Variants: Circular Queue, Priority Queue, Deque. Used in scheduling, buffering.

2.2 Non-Linear Data Structures

Tree – Hierarchical structure. Types: Binary Tree, Binary Search Tree (BST), AVL Tree, Heap. Used for efficient searching and hierarchical data.

Graph – Nodes (vertices) + edges (connections). Types: Directed, Undirected, Weighted. Used in networks, maps, dependencies.

2.3 Hash Based Data Structures

Hash Table / Map – Key-value storage for quick lookup and insertion.


## **3. Algorithms**

3.1 Searching Algorithms

Linear Search – O(n)

Binary Search – O(log n) (requires sorted array)

3.2 Sorting Algorithms

Bubble Sort – O(n²)

Selection Sort – O(n²)

Insertion Sort – O(n²)

Merge Sort – O(n log n)

Quick Sort – O(n log n) average, O(n²) worst-case

3.3 Graph Algorithms

BFS (Breadth-First Search)

DFS (Depth-First Search)

Dijkstra’s Algorithm – Shortest path

Kruskal / Prim Algorithm – Minimum Spanning Tree

3.4 Dynamic Programming (DP)

Solve complex problems by breaking them into subproblems.

Examples: Fibonacci, Knapsack Problem, Longest Common Subsequence

3.5 Greedy Algorithms

Make the best choice at each step.

Examples: Activity Selection, Huffman Coding


## **4. Complexity Analysis**

Time Complexity: How fast an algorithm runs.

Space Complexity: How much memory an algorithm uses.

Big O Notation: Express efficiency (O(1), O(n), O(n²), O(log n), etc.)


## **5. Real-Life Analogies**
Data Structure	Analogy
Array	Bookshelf with fixed slots
Linked List	Train with connected carriages
Stack	Stack of plates (LIFO)
Queue	People standing in line (FIFO)
Hash Table	Dictionary (fast lookup by key)


## **6. Summary**

DSA is the combination of data structures and algorithms.

Data Structures organize data efficiently.

Algorithms solve problems efficiently.

Mastering DSA improves coding skills, prepares for interviews, and enables solving complex problems with optimal performance.
